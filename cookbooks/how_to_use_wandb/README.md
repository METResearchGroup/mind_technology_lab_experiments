# How to use Weights and Biases (Wandb)

Weights and Biases is a tool that helps with AI/ML experiment tracking.

Let's say that we have the following questions:

1. Can we prompt-tune a model to be a strong moral outrage classifier?
2. Can we fine-tune a model to be a strong moral outrage classifier?

Each of these is an empirical research question which will require a lot of tweaking and tuning. Normally, you have to do this by yourself. It's really hard to track all the different versions of the things that you tried. However, tools do exist that allow you to keep track of the different knobs turned and the things that you tweak, and to easily look at the results across experiments.
