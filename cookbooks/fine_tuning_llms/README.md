# Fine-tuning 101

For this, we'll use SmolLM, from HuggingFace, as these are very small models that train fast, improve rapidly, and can showcase how to work with these models.

Key methods we'll go over here include:

- Dataset preparation
- Evaluations
- Benchmarks
- Fine-tuning methods: SFT, RLHF, RLVR, DPO, GRPO
