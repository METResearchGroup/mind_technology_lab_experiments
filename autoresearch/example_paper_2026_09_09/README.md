# example_paper_2026_09_09

This is a template replication folder. It shows the naming convention
`{paper_name}_{YYYY_MM_DD}` and the per-folder `pyproject.toml` layout.

To start a real replication, copy this folder, rename it to match the paper and
the request date, edit `pyproject.toml` with the dependencies you need, and run
`uv sync --extra test` from the repository root. You can delete this template.
